# AI Personalized Learning Coach 🎓

## Project Overview
AI Personalized Learning Coach is an AI-powered web application that helps students create personalized study plans, practice quizzes and track their learning progress.

## Technologies Used
- Python
- Streamlit
- Google Gemini AI
- SQLite
- Python-dotenv

## Features
1. AI Personalized Study Planner
2. AI Quiz Generator
3. Automatic Quiz Evaluation
4. Student Performance Tracking
5. SQLite Database Integration

## Installation

1. Clone the repository.
2. Install required libraries:

pip install -r requirements.txt

3. Create a .env file and add your Gemini API key:

GEMINI_API_KEY=your_api_key

4. Run the application:

streamlit run app.py
